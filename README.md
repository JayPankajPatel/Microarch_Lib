# Microarch_Lib
This is a collection of RTL modules that are to be reused throughout my projects.

# Setup
- Simply run `scripts/setup.sh`


# Environment Management
- This environment is managed by [pixi](https://pixi.prefix.dev/latest/)
- RTL dependencies are managed by [Bender](https://github.com/pulp-platform/bender)
- Verification is handled by [cocotb](https://www.cocotb.org/)
